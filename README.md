## 💻 Featured Projects

### 01. Smart Attendance System

**IoT • ESP32 • RFID • Blynk • Google Sheets API**

An automated attendance tracking system using ESP32 and RFID-based identification. Each scan records attendance data, synchronizes information with Google Sheets, and supports live monitoring through Blynk. Gmail SMTP integration enables automated parent notifications.

**[View Repository](https://github.com/Bhavya-Shriivastava/Smart-Student-Tracking)**

### 02. Skin Cancer Detection Using CNN

**Python • Deep Learning • CNN • Image Processing**

A convolutional neural network prototype for classifying skin-lesion images. The project incorporates image preprocessing, normalization, data augmentation, and model optimization to explore AI-assisted screening applications.

*This is an educational prototype, not a clinical diagnostic tool.*

**[View Repository](https://github.com/Bhavya-Shriivastava/skin-cancer-detection)**

### 03. National Wildlife Conservation Intelligence Platform

**React • FastAPI • PostgreSQL • PostGIS • Machine Learning • RAG**

A conservation intelligence platform integrating wildlife observations, geospatial visualization, risk classification, anomaly detection, and AI-assisted information retrieval.

The platform combines interactive mapping with a spatial database and source-cited retrieval to support wildlife data exploration.

**[View Repository](https://github.com/Bhavya-Shriivastava/national-wildlife-conservation-intelligence)**

### 04. Spotify to YouTube Converter

**Python • Spotipy • Spotify API • YouTube Data API • OAuth**

A command-line application designed to transfer public Spotify playlists into YouTube playlists. It retrieves tracks, searches for matching videos, authenticates users through Google OAuth, and creates playlists on YouTube.

**[View Repository](https://github.com/Bhavya-Shriivastava/spotify-youtube-converter)**
